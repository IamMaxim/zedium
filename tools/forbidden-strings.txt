# ACP agent registry — offline-only freeze (Patch 0035; revised for the v1.5.4 rebase)
#
# Patch 0036 originally *deleted* the registry subsystem (the empty "Add More
# Agents" UI, the AgentRegistryStore, and the LocalRegistry archive/npx agents).
# Upstream v1.5.4 then refactored this subsystem: it unified the old `Extension`
# (keep) and `Registry` (strip) settings variants into a single `Registry`
# variant (#[serde(alias = "extension")]) backed by AgentRegistryStore, with an
# EXTENSION_TO_REGISTRY_IDS migration path. A literal replay of 0036's deletion
# would break extension-provided agent support. So on the v1.5.4 rebase we keep
# the model of patch 0035 (and the extension-registry freeze in 0016): the store
# is frozen OFFLINE-ONLY rather than removed. AgentRegistryStore /
# LocalRegistryArchiveAgent / LocalRegistryNpxAgent therefore remain in the tree,
# but with their remote-fetch surface deleted (see 0035) — they resolve agents
# only from the on-disk cache, which is never populated over the network. The
# air-gap guard is the egress ban above (cdn.agentclientprotocol.com), not the
# presence of these symbols, so the 0036 symbol tripwires are intentionally gone.
